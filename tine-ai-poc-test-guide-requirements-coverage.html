10-Minute Demo Walkthrough

1
Login as Admin & review Dashboard
Admin
Click the Admin quick-fill button on the login screen, then sign in. The dashboard shows dataset counts (total, approved, under review, uploaded), active suppliers/clients, recent audit activity, and the African language coverage banner.
  • Observe stat cards: 6 datasets seeded across Yoruba, Swahili, Cameroonian French, Amharic, Zulu, Hausa
  • See the "TINE AI Controlled" badge in the top-right — emphasises central control
Proves: Central control layer exists
2
Browse & filter Datasets
Admin
Go to Datasets in the sidebar. Six African-language datasets are listed. Use the filters to narrow by status, type, or language.
  • Filter by Status: approved — shows 3 datasets (Yoruba, Cameroonian French, Zulu)
  • Filter by Type: audio — shows audio-only entries
  • Filter by Language: Hausa — shows the image dataset
Proves: Dataset listing, search & filtering (RUD §6.3)
3
View a Data Card
Admin
Click the Swahili News Broadcast Archive (status: Under Review). The Data Card shows all metadata fields from RUD §7.
  • Language, country, dialect, cultural context, source, file size, format
  • AI transcription output box (pre-computed Swahili text + translation)
  • Annotation details, quality score, rights & licensing
  • Workflow sidebar showing current stage highlighted
Proves: Data Card management (RUD §7)
4
Upload a new Dataset (as Supplier)
Supplier
Log out, log in as Supplier, then go to Upload Dataset. Fill in the form with a new African-language entry.
  • Name: "Igbo Market Chatter", Type: Audio, Language: Yoruba (or type "Igbo"), Country: Nigeria
  • Add dialect, cultural context, source, rights info
  • File is optional — submit without a file to demo metadata-only upload
  • Dataset appears in the list with status Uploaded
Proves: Supplier upload flow (RUD §4.2, §6)
5
Run the Processing Workflow + AI Enrichment
Admin
Log back in as Admin. Open the dataset you just uploaded (status: Uploaded). Walk through each workflow step.
  • Click "Start Processing" → status moves to Processing
  • Click "Run AI Enrichment" → transcription & dialect annotation appear instantly (realistic African-language mock output)
  • Status automatically advances to Under Review
  • Now click "Approve Dataset" → status becomes Approved, audit entry created
  • Alternative: click "Reject", enter a reason — shows rejection reason on the card
Proves: Processing workflow, AI enrichment, TINE AI approval authority (RUD §8, §8.3, §9)

Admin

  • Select Client: Dr. Sarah Chen
  • Select Dataset: the one you just approved

Proves: Client/project assignment, licensing (RUD §5, §10.1, §14)
7
Client Portal — scoped view
Client
Log out, log in as Client (Dr. Sarah Chen). Go to Client Portal.

8
Generate API Key & Test Live API Call
Client
Go to API Access. This is the "wow" moment for a technical audience.
  • Click "Generate API Key" — a tine_xxx... key appears with a copy button
  • Copy the key, paste it into the Live API Demo panel below
  • Enter a Dataset ID (e.g. 1 or 2) in the second box
  • Click "Test API Call" — real authenticated HTTP call fires, JSON response renders instantly
  • Response includes: dataset name, language, dialect, version, transcription sample, quality score, license
  • Try a wrong key or unassigned dataset ID — see 401/403 error responses
Proves: API-based access model, key auth, access control enforcement (RUD §10, §10.3)

Admin
Log back in as Admin. Go to Audit Log. Every action from the demo is recorded.

  • Click action-filter buttons (e.g. API_ACCESS, AI_ENRICH) to isolate event types
  • Each row shows: timestamp, actor name, role, action, entity type & ID, full detail text
Proves: Full audit trail — who did what and when (RUD §16)

Swagger API Testing (Alternative)

Open http://localhost:8500/docs for the interactive Swagger UI. You can test every endpoint directly:

  • POST /api/auth/token — login, get JWT token
  • GET /api/datasets/ — list datasets (use Authorize button with Bearer token)
  • PATCH /api/datasets/{id}/status — advance workflow state
  • PATCH /api/datasets/{id}/enrich — trigger AI enrichment
  • POST /api/access/assign — assign dataset to client
  • POST /api/access/apikeys/generate — generate API key
  • GET /api/access/datasets/{id}/data?api_key=... — test API key access
  • GET /api/audit/ — view full audit trail
